## 背景与动机

- 文字驱动的副本成本高（350 段 ≈ 1.75 万字），用户提出"不做副本，还有什么玩法"
- 参考 QQ 宠物玩法体系（三维数值/打工/学习/装扮/互动/宠物语）
- 用户拍板方向：**把副本换成"打工学习"**（数值循环，文字只做点缀）
- 数值维度拍板：**A 方案 = 金钱 + 三围（武力/智力/魅力）**
- 时间尺度拍板：**以 20 年为单位设计**（陪伴型，不是数值爽游）

## 设计哲学（20 年尺度的反转）

**不是"玩 20 年游戏"，是"养了 20 年的宠物，它记得你"**：
- 年轮式成长（现实时间 = 游戏时间，数值慢增长 10-20%/年，20 年不崩）
- 内容复用（模板池 × 年轮变体 + 数据生成回忆）——不靠写 20 年文案
- 情感锚点（生日/纪念日/年度报告）是骨架，数值是背景

## 四阶段循环框架（前期到终局）

| 阶段 | 时长 | 新机制层 |
|------|------|---------|
| 前期 | 0-20h | 打工入门 + 三维状态（饿/心情→收益×1.2） |
| 中期 | 20-80h | 学习（属性分流）+ 装备系统（效率×N） |
| 后期 | 80-200h | 投资经营（钱生钱，被动收入>打工收入） |
| 大后期 | 200h+ | 转世 prestige + 图鉴收集（收集控目标） |

- 每个阶段解锁**新机制**（不只是数字变大）——循环不塌的关键
- 目标节奏：小目标 30-60min / 中目标 2-4h / 大目标 10-20h / 阶段目标 40-100h

## 20 年支柱（年轮成长表）

| 现实年 | 宠物阶段 | 解锁 |
|--------|---------|------|
| 0-2 | 幼年（刚卡入后室） | 打工（搬砖厂） |
| 3-5 | 少年 | 学校（属性学习） |
| 6-9 | 青年 | 职业阶梯 + 装备 |
| 10-14 | 成年 | 投资经营 |
| 15-19 | 中年 | 退休规划（宠物养老，玩家反过来养它） |
| 20+ | **传承** | 下一代蛋（继承记忆） |

## 机制改动方案 M1-M6

### M1 时间维度：现实日历同步
- 存档记录首次启动日期 + 玩家生日（新增字段）
- 年轮阶段 = 首启日期至今的现实年数（自动推进，零操作）
- holiday.cjs 扩展为"日历事件源"（生日/纪念日/年度）

### M2 年轮阶段系统（stage）
- 幼年(0-2y)→少年(3-5y)→青年(6-9y)→成年(10-14y)→中年(15-19y)→传承(20y+)
- 阶段影响：可用副本（职业阶梯解锁）、宠物语变体（同模板不同口吻）、UI 配色/表情
- 纯时间计算

### M3 数值系统（金钱+三围+状态）
- 存档新增：gold / force·int·charisma / hunger·mood
- 打工收益结算：副本内挂机 tick 累积工资（职级系数 × 属性系数 × 状态倍率 × 年轮加成）
- 消耗：买食物（状态回复）、装备（效率/属性加成）
- 曲线：年增长 10-20%（慢数值）

### M4 回忆生成系统（20 年不写文案的技术核心）
- 数据源：现有日志系统 + 存档统计（等级/事件/打字数/节日）
- 生成：模板 + 数据插值（"去年今天，你刚升组长""你昨晚两点才睡"）
- 触发：日常随机 / 纪念日 / 年度报告
- **待确认**：现有 logs 够不够，还是要存档加轻量"事件历史"标记

### M5 年度仪式
- 生日（存档字段）→ 每年专属事件（模板×年轮）
- 相遇纪念日（首启日期）→ 周年回 L0 回忆
- 年度报告（年底）："这一年，我们挂机 X 小时、你打了 X 字、宠物升到 Lv.X"

### M6 传承系统（20 年终极）
- stage=20 年 → 生成下一代蛋：软重置（金钱/属性清零，等级/称号保留），继承记忆标记（"妈妈说过你爱在晚上打字"）
- 告别变新生，陪伴不断代
- **待确认**：软重置范围（金钱/属性清零、等级保留）是否认可

## 架构关键决策

**年轮/仪式/回忆全部走"全局系统"（宠物语/气泡/面板），不进副本事件表**——副本只放打工日志（模板化）——20 年机制与副本文字成本完全解耦。

## 美术评估（无美术资源约束）

| 模块 | 需求 | 实现 |
|------|------|------|
| M1/M4 | 无 | 纯逻辑/文本 |
| M2/M3/M5 | 极小 | CSS 变量配色/进度条/卡片排版/emoji |
| M6 | 极小 | 蛋 = CSS 渐变圆 + 表情 emoji + 孵化动画（CSS 关键帧） |

**结论：美术成本 ≈ 0，全部代码+样式活。**
