# 小说改编指南（ScenarioWriter 改编模式）

本指南定义"把小说/剧本/大纲改编为 Idel-DreamMaker 副本"的完整流程。
进入改编模式后，按 A-G 阶段顺序执行。

## 0. 映射决策（先定产物形态）

| 作品体量 | 推荐映射 | 说明 |
|---------|---------|------|
| 中短篇/单卷 | **一部 → 一个副本**（推荐） | 主角人生线拆 500 级；原著结局为主结局，分支做"如果当时选另一边" |
| 多卷长篇（如三部曲） | 每卷 → 一个副本 | 玩家逐本通关，经验累入大厅（大厅多副本机制天然支持） |
| 极短篇/大纲/脑洞 | 一个副本（简配） | 主线周目起步，max_rebirth 0 |

**通用建议：先做单周目（max_rebirth 0）跑通，再按需扩展周目。** 不要一上来承诺 4 周目（8760 条事件，工程巨大）。

> 改编不是逐句转换，而是"再创作"：保留原著气质与关键情节，用挂机副本的形式重新演绎。500 级人生线需要大量填充内容，原著名场面占比约 20-30%，其余为符合世界观的展开。

## A. 原著摄入

- 读小说/剧本/大纲（支持整本文件）
- 过长时：先读目录/梗概 → 分卷读 → 提炼关键信息，与用户确认理解正确
- 收集：世界观规则、主角线、关键人物、名场面、结局

## B. 风格指纹提取（给用户确认）

提炼四件事（各 2-3 句）：
1. **叙述温度**：冷峻/温暖/戏谑/史诗…
2. **对白规则**：谁说话简短、谁啰嗦；称呼方式
3. **节奏型**：铺陈多长、高潮密度
4. **视角策略**：主角视角为主？是否有群像段落？

> 风格指纹写入状态文件，生成每批时对照——防止"写歪"（改编成另一部小说的味道）。

## C. 人生线拆 500 级（按原著结构，不硬套模板）

按原著的实际结构分段（参考 SKILL.md 的三模板但不强制），例如三幕式小说：
```
Lv.1-40    夏尔日常（原著慢热铺垫）
Lv.41-120  出发与第一转折
Lv.121-260 中段高潮（战争密集段）
Lv.261-400 深入敌境（压抑个人段）
Lv.401-500 决战与归乡（收束）
```
输出分段表给用户确认。**硬约束同原创模式**：Lv.1 开头、500 级前留收尾、choice 均匀。

## D. 名场面 choice 化

- 原著关键抉择（3-6 个）→ 命运选择（决定结局归属）
- 态度性选择（对某角色/阵营的态度）→ 态度选择（数值 flag）
- 路线分叉 → 路径选择（branch 切换或平行线）
- 每 100 级均匀分布

## E. 平行线设计

"如果当时选了另一边会怎样"：
- 选 A → 忠实原著走向
- 选 B → 平行线（10-15 级深度，然后汇合或导向条件结局）
- 平行线内容必须同等饱满（参考废土"阿强平行线"先例）

## F. 分支与结局规划

- 分支数：2-4 个（按原著的关键路径分叉定，不是固定 4 个）
- 每分支：1 个主结局（**忠实还原原著结局**）+ 2-4 个条件结局（平行线的结果）
- **无条件兜底硬规则**：每分支最后一行事件 FlagRequire 留空
- 输出结局规划表给用户确认

## G. 填充与锚点化

- 世界观锚点表：从原著提取（角色 3-5 核心 + 5-8 配角池 / 地点 6-10 / 群体 4-6 / 威胁 3-5 / 物件 2-3），**超出原著的取值必须与原著世界观一致**
- 填充内容（非名场面部分）围绕锚点展开，保持世界观统一
- **此阶段执行 SKILL.md 的 Stage 1.7 初始化状态文件**（scenarios_wip/{id}/ 下 meta.md / content.md / state.md / log.md / batches/），并把 B 阶段确定的"风格指纹"写入 state.md 的"基本信息"小节
- 然后进入三稿制流程（与原创模式相同：小批分片 → 每批全量展示 → 粗稿/细稿/精校）

## 版权提示

- **个人游玩**：改编任意小说/剧本无限制
- **公开分享**：改编有版权作品需获得原作者授权（副本作为开源仓库内容发布时尤其注意）
- 建议在副本描述中注明"改编自《XXX》"
- **公版作品**（作者逝世 50 年以上，如《指环王》托尔金、《西游记》《三国演义》等）可自由改编；现代在世作者的作品（如《三体》刘慈欣）需授权

## 续写

改编模式同样受上下文长度约束（1M token 下单周目三稿可跑完，4 周目需切会话）。
中断后使用**续写模式**：读 scenarios_wip/{id}/ 状态文件从断点继续，风格指纹与规划表都在状态文件里，不会丢。
